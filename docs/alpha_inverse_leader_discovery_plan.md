## 1. 💡 핵심 개념 정리

### 새로운 원칙
| 레이어 | 역할 | 결과물 |
|--------|------|--------|
| **Layer 1** | 기간별 팩트 기반 분류 | 대장주 / 대장후보 / 피크아웃 경보 / 피크아웃 확정 배지 |
| **Layer 2** | 4개 기간 크로스 패턴 통합 | 눌림목 후보 / 신흥 급부상 / 종료 감지 |

## 2. 🏗️ Layer 1: 기간별 기계적 분류 (Track B 화면)

### Step 1: 대장주 / 대장후보 판별 (랭킹 기반, 단순 명확)

```
정렬 기준: 기간 내 시장 대비 알파 (totalChangeRate - marketIndexChange), 내림차순

상위 1/3 (Top 10 of 30):   👑 대장주     — 해당 기간의 실질 리더 (팩트 기록)
중위 1/3 (11~20 of 30):    🚀 대장후보   — 뒤를 잇는 예비 후보
하위 1/3 (21~30 of 30):    (배지 없음)   — 단순 관찰 대상
```

> 우리로(폭등 후 하락 중)도 기간 알파 상위면 "대장주"로 기록 → 하지만 피크아웃 배지가 추가될 수 있음.

### Step 2: 거래정지일 보정 (Trading Halt Guard)
```
- trading_value == 0인 날 → alphaTimeline에서 null 처리 (UI: 회색 '-' 바)
- 승/패 판정에서 제외, validAlphaDays = 실제 유효 거래일 수만 카운트
```

## 3. 🚨 피크아웃 감지 시스템 (v4 — 스코어링 + 2단계 경보)

### 핵심 철학

| | 기존 방식 | v4 스코어링 방식 |
|---|---|---|
| **타이밍** | 이미 -15% 빠진 후 진단 (사후 확인) | 음봉·거래대금 패턴으로 **당일 감지** (예측적 조기 경보) |
| **데이터** | 종가만 사용 | OHLC 전체 + 일별 거래대금 패턴 활용 |
| **정밀도** | 단순 낙폭 임계값 | 복합 패턴 점수 합산으로 오탐(False Positive) 최소화 |
| **배지** | ☠️ 피크의심 단일 | ⚠️ 경보(2~4점) / ☠️ 확정(5점+) 2단계 구분 |

### 피크아웃 패턴 5종 (상세 명세)

#### Pattern 1 — 바이잉 클라이맥스 Buying Climax (+3점, 신뢰도 ★★★★★)
```
광전자가 보여주는 바로 그 패턴. 세력·기관이 마지막 대물량을 개인에게 매도하는 구간.

감지 조건:
  - 해당 날의 거래대금 ≥ 기간 내 평균 거래대금의 3배 이상
  - AND 그 날이 음봉 (close < open)
  - AND 당일 고가(high)가 기간 내 최고점의 85% 이상 (꼭대기 근처)

해석: "가장 많은 돈이 들어온 날에 음봉" = 엄청난 물량을 누군가 내다팔고 있음
```

#### Pattern 2 — 위꼬리 장대봉 Shooting Star (+2점, 신뢰도 ★★★★)
```
장중 고점까지 치솟았다가 결국 아래로 밀리는 패턴.

감지 조건:
  - 위꼬리 비중 = (high - close) / (high - low) > 0.6  (변동폭의 60% 이상이 위꼬리)
  - AND 거래대금 ≥ 기간 평균의 2배
  - AND 당일 고가가 기간 내 최고점의 85% 이상

해석: "올라가려는 힘이 있었지만 결국 눌렸다" = 저항선에서 스마트머니의 매도
```

#### Pattern 3 — 갭업 키리버설 Gap-up Key Reversal (+3점, 신뢰도 ★★★★★)
```
가장 강력한 단기 피크아웃 신호. 상승 갭으로 열었지만 결국 전일 종가 아래로 마감.

감지 조건:
  - 시가 > 전일 종가 (갭 상승 출발)
  - AND 현재 종가 < 전일 종가 (갭을 완전히 반납 + 더 밀림)
  - AND 거래대금 ≥ 기간 평균의 1.5배

해석: "기대감으로 샀지만 이미 세력은 팔고 있었다" → 당일 강세 반전 실패
```

#### Pattern 4 — 연속 음봉 + 거래대금 증가 (+2점, 신뢰도 ★★★)
```
하락하는데 거래가 늘어나는 것 = 공격적 매도 물량이 나오고 있음.

감지 조건:
  - 최근 3일 연속 음봉 (close < open)
  - AND 최근 3일 평균 거래대금 > 그 이전 3일 평균 거래대금

해석: "파는 사람이 점점 많아지고 있다" = 하락 압력 증가 확인
```

#### Pattern 5 — 신고가 갱신 실패 + 거래량 다이버전스 (+2점, 신뢰도 ★★★★)
```
추세 후반부 전형 특징. 가격은 신고가를 시도하지만 거래량이 이전보다 약해지는 것.

감지 조건:
  - 오늘 고가 ≥ 기간 내 직전 최고점 (신고가 도전)
  - AND 오늘 거래대금 < 이전 최고점 갱신일 거래대금의 70% 미만
  - AND 오늘 종가 < 오늘 고가의 95% (고점에서 끌어내려짐)

해석: "더 올리려는데 힘이 없다" = 모멘텀 소진 최초 신호 (조기 경보에 최적)
```

#### Bonus — 기간 내 고점 대비 낙폭 (+1점)
```
- drawdownFromPeak >= 10%: +1점 (보조 지표)
- drawdownFromPeak >= 20%: +2점 (사후 확인이지만 추가 가중)
```

### 피크아웃 2단계 경보 배지

```
peakoutScore = Pattern 1~5 점수 합산 + 낙폭 보너스

peakoutScore 0~1점: 배지 없음 (정상)
peakoutScore 2~4점: ⚠️ 피크아웃 경보 (주의, 노란색 배지)
peakoutScore 5점+:  ☠️ 피크아웃 확정 (강한 경고, 붉은 배지)
```

| 배지 | 색상 | 의미 | 투자 시사점 |
|------|------|------|------------|
| ⚠️ 경보 | 황색 | 피크아웃 조짐 감지, 추가 확인 필요 | 신규 매수 자제, 보유시 손절선 확인 |
| ☠️ 확정 | 적색 | 복합 패턴 다중 감지, 높은 신뢰도 | 매수 금지, 보유시 즉시 익절 검토 |

> **핵심**: 둘 다 대장주(👑)와 공존 가능. 예: `👑 대장주 + ☠️ 피크아웃 확정` = "이 기간의 리더였지만 지금은 매도 적기"

## 4. ⚙️ 피크아웃 설정 패널 (Track B UI 인라인 설정)

### 설계 의도
어떤 조건으로 피크아웃이 체크되는지 사용자가 직접 확인하고 조절할 수 있어야 한다.
패턴마다 득실이 다르므로, 사용자 성향(보수적/공격적)에 따라 켜고 끌 수 있다.

### 설정 항목

| 설정 항목 | 기본값 | 설명 |
|-----------|--------|------|
| P1. 바이잉 클라이맥스 감지 | ✅ ON | 거래대금 급증 + 고점 근처 음봉 |
| P2. 위꼬리 장대봉 감지 | ✅ ON | 고점 근처 긴 위꼬리 캔들 |
| P3. 갭업 키리버설 감지 | ✅ ON | 갭 상승 후 전일 종가 아래 마감 |
| P4. 연속 음봉 + 거래대금 증가 | ✅ ON | 3일 연속 음봉 + 물량 증가 |
| P5. 신고가 갱신 실패 | ⬜ OFF | 거래량 다이버전스 감지 (실험적) |
| 낙폭 기준선 (%) | 15% | 기간 내 고점 대비 낙폭 경계선 |
| 경보 임계 점수 | 2점 | N점 이상 시 ⚠️ 경보 |
| 확정 임계 점수 | 5점 | N점 이상 시 ☠️ 확정 |

### UI 배치 방안
```
[Track B 탭 우측 상단]
  기존: [새로고침] [테마 파편화 정리 AI]
  추가: [⚙️ 피크아웃 설정] 버튼 → 클릭 시 드롭다운 패널 펼침

드롭다운 패널 내용:
  ┌─────────────────────────────────────┐
  │ ⚙️ 피크아웃 감지 설정              │
  │─────────────────────────────────────│
  │ ☑ P1. 바이잉 클라이맥스      [+3점] │
  │ ☑ P2. 위꼬리 장대봉          [+2점] │
  │ ☑ P3. 갭업 키리버설          [+3점] │
  │ ☑ P4. 연속음봉+거래대금증가  [+2점] │
  │ □ P5. 신고가 갱신 실패       [+2점] │
  │─────────────────────────────────────│
  │ 낙폭 기준: [15]%                    │
  │ ⚠️ 경보 기준: [2]점 이상           │
  │ ☠️ 확정 기준: [5]점 이상           │
  └─────────────────────────────────────┘

설정은 localStorage에 저장하여 재시작 후에도 유지
```

## 5. 🔭 Layer 2: 크로스-기간 통합 패턴 분석 (다음 스프린트)

같은 종목이 5d/10d/20d/60d에서 어떤 위치를 차지하는지 비교 → 4기간 패턴으로 진짜 상태 파악.

| 패턴명 | 60d | 20d | 10d | 5d | 해석 |
|--------|-----|-----|-----|----|------|
| 🔥 진성 대장주 | 대장 | 대장 | 대장 | 대장 | 4기간 모두 리더 |
| 🆕 신흥 급부상 | - | - | 대장/후보 | 대장 | 최근 갑자기 치고 올라옴 → AI 딥다이브 후보 |
| 📉 눌림목 후보 | 대장 | 대장 | 후보/없음 | 후보/없음 | 장기 리더이나 최근 이탈 → AI 딥다이브 후보 |
| 💀 시세 종료 | 대장 | 대장 | 없음 | 없음 | 2개 기간 연속 이탈 → 피크아웃 확정 |
