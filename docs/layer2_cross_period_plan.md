> **작성일**: 2026-04-09

## 1. 핵심 목표

Layer 1이 **단일 기간 내** 팩트(대장주/피크아웃)를 기록한다면,  
Layer 2는 **4개 기간(5d/10d/20d/60d)**을 교차 비교하여 "이 종목이 지금 어떤 생애주기(Life-cycle)에 있는가"를 판별하고, **실제 매수 가능한 종목을 추천 카테고리별로 상호 베타적으로 분류**합니다.
더불어 종목의 성격을 나타내는 독립적인 **크로스 시그널(배지)**을 복수로 부여합니다.

> [!IMPORTANT]
> Layer 2는 **매수 신호가 아니다**. "매수 후보군 분류"이다.  
> 실제 매수 결정은 Layer 3 (AI 딥다이브)에서만 내려진다.
> 모든 연산은 달력 날짜가 아닌 **KODEX 200 기반 영업일(캔들) 기준**으로 처리하며, 파생상품(ETF/ETN/SPAC 등)은 런타임에서 철저히 격리된다.

---

## 2. 메인 추천 카테고리 (Exclusive Classification)

한 종목은 오직 1개의 메인 카테고리에만 소속됩니다.

### 2.1 🔥 신흥 급부상 (EMERGING_STAR)

| 기간 | 60d | 20d | 10d | 5d |
|------|-----|-----|-----|-----|
| 랭크 | NONE~CANDIDATE | NONE~CANDIDATE | CANDIDATE~LEADER | **LEADER** |
| 피크아웃 | - | - | NONE | **NONE** |

**정의**: 장기적으로는 무명이었으나 **최근 5~10일간 갑자기 알파가 폭발**한 종목.  
단, 최근 60일 내 고점에서 15% 이상 크게 하락한 이력이 없는 순수한 초기 상승 동력을 포착합니다.

**판별 로직**:
```
조건 (AND):
  1. period_5d.phase == 'LEADER'
  2. period_5d.peakoutLevel == 'NONE'
  3. period_60d.phase != 'LEADER' (장기 대장이 아니었음)
  4. period_5d.marketAlpha > period_20d.marketAlpha (단기 가속 확인)
  5. drawdownFromPeak < 15% (최근 고점에서 큰 낙폭이 없었음)
```

**투자 시사점**: 🔥 가장 공격적 매수 후보. 초기 모멘텀 구간이라 빠르게 편승하면 이익.

---

### 2.2 🔥 눌림 반등 (PULLBACK_REBOUND) — **신규**

| 기간 | 60d | 20d | 10d | 5d |
|------|-----|-----|-----|-----|
| 랭크 | NONE~LEADER | NONE~CANDIDATE | CANDIDATE~LEADER | **LEADER** |

**정의**: 최근 60일 내 고점에서 한 차례 거대한 하락(조정)을 거친 후, **최근 며칠간(5일) 압도적인 수급과 함께 단기 대장주로 복귀**하며 모멘텀을 강하게 턴어라운드 시킨 종목.

**판별 로직**:
```
조건 (AND):
  1. 위 신흥 급부상(EMERGING_STAR)의 조건 1~4를 만족 (단기 모멘텀 가속)
  2. drawdownFromPeak >= 15% (최근 60일 고점 대비 15% 이상 크게 무너진 이력 존재)
```

**투자 시사점**: 과대 낙폭 이후의 2차 시세 진입 또는 강력한 V자 반등. 인간 트레이더의 '바닥권 턴어라운드' 직관과 가장 잘 부합.

---

### 2.3 📉 눌림목 (PULLBACK_DIP)

| 기간 | 60d | 20d | 10d | 5d |
|------|-----|-----|-----|-----|
| 랭크 | **LEADER** | LEADER~CANDIDATE | CANDIDATE~NONE | CANDIDATE~NONE |
| 피크아웃 | NONE | NONE | NONE~ALERT | **NONE** |

**정의**: 장기적으로 확인된 대장주인데, **최근 5~10일 단기 조정을 받는 중**. 아직 하락 반전(피크아웃)이 확정되지 않아 2차 파동 진입을 기다리기 좋은 자리.

**투자 시사점**: 📉 장기 추세가 살아있는 거인의 어깨에 탑승할 기회. (단기간 소폭 조정을 겪는 중)

---

### 2.4 👑 진성 대장주 (TRUE_LEADER)

| 기간 | 60d | 20d | 10d | 5d |
|------|-----|-----|-----|-----|
| 랭크 | **LEADER** | **LEADER** | **LEADER** | **LEADER** |
| 피크아웃 | - | - | - | ANY |

**정의**: 4기간 모두 최상위 랭크를 유지하는 **진정한 시장의 주도주**.  
가장 안전하지만 피크아웃 경계 알럿이 뜨면 관망해야 합니다.

---

### 2.5 💀 시세 종료 (EXHAUSTED)

**정의**: 과거 대장주였지만 최근 10~5일 연속 랭킹 이탈 + **피크아웃 시그널 확정**된 종목. (매수 금지)

## 3. 보조 시그널 (Auxiliary Signals)

메인 카테고리와 **독립적으로 복수 부여**되며, 종목의 세부 패턴을 알려줍니다. UI 상 배지 형태로 표기됩니다.

### 3.1 🌱 순위 상승형 (RANK_CLIMBER)
- **정의**: 최근 20봉을 4개의 5일 단위 구간으로 나누었을 때, 순위가 계단식으로 우상향하며 탄탄한 수급을 증명하는 종목.
- **판별**: `trendScore >= 2` (3번의 구간 이동 중 2번 이상 순위 상승), 전체적 우상향 확인, 최근 20일 내 최소한 300위 권(상위 12%) 안에 한번은 진입할 것. 단기 급등주가 아닌 "선행 포집"의 핵심 지표.

### 3.2 📊 꾸준함 (HIGH_CONSISTENCY)
- **정의**: 최근 30일을 6구간(5일씩)으로 나누었을 때, 무려 4번 이상 최상위권(LEADER)에 진입한 극도로 신뢰성 높은 종목. (구 장기질주의 역할을 계승)

### 3.3 ⚡ 브레이크아웃 (BREAKOUT_CANDIDATE) / 🟩 거래폭발 (VOLUME_SURGE)
- 최근 추세선 돌파 가속화 및 거래대금 폭발 감지용 시그널.

---

## 4. 분류 우선순위 (Priority Resolution)

1종목이 여러 조건에 부합할 경우 아래 순서대로 먼저 격리/분류합니다.
```
1. EXHAUSTED        ← 최우선 격리 (위험 종목 제거)
2. TRUE_LEADER      ← 4기간 모두 LEADER
3. EMERGING_STAR    ← 초기 모멘텀 장착 신흥 강자
4. PULLBACK_REBOUND ← 낙폭과대 턴어라운드 (바닥 탈출)
5. PULLBACK_DIP     ← 주도주의 단기 눌림목
6. UNCLASSIFIED     ← 위 기준에 미달
```
