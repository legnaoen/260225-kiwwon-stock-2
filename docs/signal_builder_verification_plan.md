# ✅ StockSignalBuilder 통합 검증 계획서
## AI 실행 이력 기반 수동 검증

---

## 검증 방법

1. **설정 > AI 실행 이력** 화면 진입
2. 가장 최근 `PM2_PORTFOLIO_REVIEW` 실행 항목 클릭 → **프롬프트** 탭 전체 복사
3. 아래 5개 영역의 평가 기준에 맞추어 붙여넣기한 텍스트를 확인
4. 각 항목에 ✅ / ⚠️ / ❌ 를 기입하여 결과를 알려주면 진단해드립니다

> [!NOTE]
> 검증 대상은 **프롬프트(prompt)** 필드 안의 팩트시트(Dossier) 텍스트입니다.
> result 필드가 아닌, AI에 보낸 입력 텍스트를 확인해주세요.

---

## 영역 1: OHLCV 신호 (전 카테고리 공통)

### 확인할 키워드
팩트시트 내에 아래 패턴이 **종목마다 1개씩** 존재하는지 확인:

```
[차트·거래량]
[이동평균]
```

### 판단 기준

| 상태 | 조건 |
|------|------|
| ✅ **성공** | `[차트·거래량]`과 `[이동평균]` 두 줄이 종목 팩트시트 안에 존재 |
| ⚠️ **부분 성공** | 두 줄 중 하나만 존재 |
| ❌ **실패** | 둘 다 없음. 또는 `[StockSignalBuilder]` 경고 로그가 콘솔에 출력됨 |

### 성공 예시
```
[차트·거래량] 🔥 거래량 폭발 (20일 평균의 2.4배) / 60일 고점 대비 -12.3%
[이동평균]    MA20 +3.1% / MA60 +8.2% / 최근 10일 양봉 7일/10일 / 거래량 증가추세
```

### 실패 예시
```
(해당 섹션 없음 — [기술적 차트 진단 (MA200)]만 존재)
```

## 영역 2: 신용비율 신호 (전 카테고리 공통)

### 확인할 키워드
```
[신용비율]
```

### 판단 기준

| 상태 | 조건 |
|------|------|
| ✅ **성공** | `[신용비율] X.X% 🟢/🟡/🟠/🔴` 형태로 종목 팩트시트 안에 존재 |
| ⚠️ **데이터 없음** | `[신용비율] 정보 없음` 으로 표기됨 (정상 동작이나 키움 API 미응답) |
| ❌ **실패** | 해당 행 자체가 없음 |

### 성공 예시
```
[신용비율] 1.8% 🟢 안전 (레버리지 부담 없음)
[신용비율] 3.8% 🔴 고신용 경고 — 추가 하락 압력 상존
```

## 영역 3: SmartMoney 수급 신호 (MOMENTUM / PULLBACK / REPORT)

### 확인할 키워드
```
[외국인]    — MOMENTUM 종목
[기관  ]    — MOMENTUM 종목
[수급 이탈] 또는 [수급 유지]  — PULLBACK 종목
[기관 확인]  — REPORT 종목
```

### 판단 기준

| 카테고리 | 성공 조건 | 실패 조건 |
|----------|----------|---------|
| **MOMENTUM** | `[외국인]`·`[기관  ]` 두 줄 모두 존재, 5일/20일 금액 표기 | 두 줄 없음 |
| **PULLBACK** | `[수급 이탈]` 또는 `[수급 유지]` 한 줄 존재 | 없음 |
| **REPORT** | `[기관 확인]` 한 줄 존재 | 없음 |
| **THEME** | SmartMoney 신호 없음 (정상 — THEME는 수급 불필요) | SmartMoney 신호가 있으면 오히려 비정상 |

### 성공 예시 (MOMENTUM)
```
[외국인] 5일 +1,450억 / 20일 +320억 (최근 가속 ✅)
[기관  ] 5일 +480억 → 외국인+기관 동시 매수 ⭐
```

### 성공 예시 (PULLBACK)
```
[수급 유지] ✅ 눌림 중 외국인 이탈 없음 (5일 +80억)
```

## 영역 4: 재무 신호 (REPORT 카테고리 전용)

### 확인할 키워드
```
[📋 재무·컨센서스 (네이버 기준)]
```

### 판단 기준

| 상태 | 조건 |
|------|------|
| ✅ **성공** | REPORT 종목 팩트시트에 위 헤더 + 분기실적/컨센서스 테이블 존재 |
| ⚠️ **데이터 없음** | 헤더는 없으나 다른 신호는 정상 (FinanceInfoCollector 타임아웃 — 35초 초과 가능) |
| ✅ **정상 제외** | MOMENTUM / PULLBACK / THEME 종목에 이 섹션이 **없음** (의도된 동작) |
| ❌ **비정상** | MOMENTUM / PULLBACK 종목에 `[📋 재무·컨센서스]`가 존재하는 경우 |

### 성공 예시 (REPORT 종목)
```
[📋 재무·컨센서스 (네이버 기준)]
# 분기별 실적
| | 2024.3Q | 2024.4Q | 2025.1Q |
|매출| 79,099 | 78,540 | 77,200 |
|영업이익| 9,184 | 6,534 | 7,100 |

# 컨센서스
목표주가 85,000원 / 현재가 64,500원
```

## 영역 5: 동작 안정성 (오류 격리 검증)

### 확인 방법
팩트시트 내 `📡 수급·재무·신용 통합 신호` 블록이 **없는 종목**을 찾아서 원인 파악

### 판단 기준

| 상태 | 조건 | 영향 |
|------|------|------|
| ✅ **정상** | 모든 종목 팩트시트에 `[📡 수급·재무·신용 통합 신호]` 헤더 존재 | — |
| ⚠️ **허용 범위** | 일부 종목에 없으나, 나머지 팩트시트는 정상 생성됨 | 해당 종목만 신호 없이 AI 평가 진행 |
| ❌ **심각** | 전체 PM2 실행이 실패하거나, 팩트시트 자체가 생성 안 됨 | PM2 전체 중단 |

> [!TIP]
> 콘솔 로그에서 `[StockSignalBuilder]` 키워드를 검색하면 신호 실패 종목과 원인을 확인 가능합니다:
> ```
> [StockSignalBuilder] 삼성전자 신호 생성 실패 (무시): Network timeout
> ```
> `(무시)` 접미사가 있으면 PM2 전체 실행은 계속됩니다 (정상적인 graceful 처리).

## 판정 기준

| 결과 | 조건 |
|------|------|
| 🏆 **완전 성공** | 영역 1~5 모두 ✅ |
| ✅ **정상 동작** | 영역 1·2 ✅ + 영역 3 해당 카테고리 ✅ + 영역 5 SUCCESS |
| ⚠️ **부분 성공** | 일부 영역 ⚠️ — 주로 Collector API 타임아웃 (기능 자체는 정상) |
| ❌ **수정 필요** | 영역 1 또는 2 ❌ — 코드 통합 문제 가능성 |
| 🔥 **긴급 대응** | 영역 5 PM2 전체 FAILED — StockSignalBuilder 블록 제거 필요 |
